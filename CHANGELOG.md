# Changelog

The source of truth for release notes: the release workflow publishes the section of the tagged version. The tag, `manifest.json` and `Cargo.toml` name one version.

## [0.1.0] - 2026-11-25

### Features

- MapGenie: the games list, each game's maps, and a map with its tiles, categories, pins, regions and labels.
- A library game opens its MapGenie title through its store ids.
